# Hermea — памятка для работы с кодом

Программа агента по аренде Hermea (Варшава): обработка фото квартир, СВК, клиенты и подбор,
рынок, собственники Otodom/OLX, перезвоны. Пользователь — Павел (Паша), пишет по-русски;
отвечать по-русски, коротко, делать самому, а не объяснять, как сделать.

**Карта кода: `program/КАРТА_КОДА.md`** — какой файл за что отвечает, данные, проверки.

## Правила

- Python 3.9 (у коллег системный Python на Mac и Windows): без `match`, без `X | Y` в аннотациях.
- Окно — Chrome в режиме приложения; классические скрипты с общим глобальным пространством
  (`i18n.js → core.js → photo.js → svk.js → templates.js → clients.js → owners.js`).
- CSS: у каждой вкладки свои приставки классов; общий класс в двух файлах ломает чужую вкладку.
- Тексты окна: ключ добавлять сразу в ru, uk и pl.
- Не коммитить: `telegram.txt`, `app_*.json`, `templates/` (шаблон договора с паспортными данными
  директора), модели `*.pt`/`*.pth`, `.venv`. Не печатать токены (`.app_port`, `telegram.txt`).
- Не обходить защиту Otodom/OLX (показ телефона за бот-защитой не трогаем).
- Файлы программы у пользователя не править руками: обновление их перезапишет. Только через релиз.

## Перед релизом

```
python3 tools/check.py --ui                # всё: ruff, CSS, JS и переводы, части, сервер, окно в Chrome
# заметки ru/uk/pl в tools/notes.json
python3 tools/build_manifest.py X.Y.Z      # сам запускает tools/check.py и не соберёт версию с ошибками
git commit … && git push                   # через 3–5 минут программы обновятся сами
```

GitHub Actions (`install-test`) ставит программу «как коллега» на Mac и Windows и гоняет
`ci_smoke.py`, `test_units.py`, `test_api.py`. Если тест падает — письмо приходит Паше на почту,
поэтому красные прогоны нельзя оставлять.
