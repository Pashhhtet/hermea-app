# Карта кода Hermea

Где что лежит и куда смотреть, когда нужно что-то поменять. Всё совместимо с Python 3.9
(на Маках коллег системный Python), окно — Chrome в режиме приложения.

## Как это устроено

```
hermea_app.py ──запускает──> app_server.py (HTTP только на 127.0.0.1, ключ в каждом запросе)
                                 │
          ┌──────────────────────┼─────────────────────────────────────────────┐
     обработка фото          данные вкладок                               фоновые проверки
  hermea.py, quality.py,   app_svk, app_clients, app_match,            app_searches (поиски, ~15 мин)
  rooms.py, sites.py,      app_owners, app_calls, app_market,          app_market (рынок, раз в день)
  app_flats.py             app_contract, otodom_text                   app_owners (Otodom + OLX, раз в день)
                                                                       app_update (обновления), утренняя сводка
окно: app/index.html ─> base.css + i18n.js + core.js, затем вкладки:
      photo.js/css · svk.js/css · clients.js/css (+ templates.js) · owners.js/css
```

## Программа (Python)

| Файл | Что внутри | Куда смотреть |
|---|---|---|
| `hermea_app.py` | запуск окна, один экземпляр, перезапуск после обновления | окно не открывается |
| `app_server.py` | сервер окна: задания, Telegram, настройки, все адреса `/api/...`, сторож закрытия | список адресов — в начале файла |
| `app_flats.py` | папка «Квартиры»: список, фото, `opis.txt`, `.hermea.json`, превью | готовые квартиры в окне |
| `hermea.py` | обработка одной квартиры: скачать, убрать водяной знак (LaMa), выровнять, цвет, логотип, описание, Telegram | качество фото, описание, отправка |
| `logos.py` | «Другое агентство»: находит логотип, который стоит на всех фото объявления в одном месте (сравнение краёв между фото) | чужой логотип не стёрся или стёрлось лишнее |
| `quality.py` | выравнивание, чистка сжатия (deblock), резкость, дизеринг — всё в float | пересветы, шум, «мыло» |
| `rooms.py` | тип комнаты по фото (CLIP), кухня первой | порядок фото |
| `sites.py` | разбор объявлений Otodom / OLX / Morizon / Gratka | сайт поменял разметку |
| `app_svk.py` | СВК: события по дням, планы, отчёт | вкладка СВК |
| `app_clients.py` | клиенты, просмотры, статусы, связь со СВК, отметки подбора | вкладка Клиенты |
| `app_contract.py` | договор PDF поверх шаблона (шаблон каждый загружает сам) | договор |
| `app_match.py` | подбор квартир клиенту: районы/комнаты из свободного текста, фильтр, оценка, дубли | «Подходящие квартиры» |
| `app_owners.py` | собственники Otodom + OLX: сбор, оценка «кому звонить», статусы, журнал и статистика звонков | вкладка Собственники |
| `app_calls.py` | перезвоны: разбор вставки (ссылка, телефон, «в пятницу»), напоминания | «Перезвоны» |
| `app_market.py` | рынок: медианы по районам и комнатам, сравнение цены, свежие объявления для подбора | вкладка Рынок |
| `app_searches.py` | «Слежу за поиском Otodom»: новые, снижение цены, дубли | левая колонка вкладки фото |
| `otodom_text.py` | длинное польское объявление «bez prowizji» | кнопка «Без комиссии» |
| `app_i18n.py` | тексты, которые присылает сервер (ошибки, уведомления), ru/uk/pl | |
| `app_update.py` | обновление с GitHub по `manifest.json` (sha256), копии в `_backup` (3 последние) | |

## Окно (`app/`)

| Файл | Что внутри |
|---|---|
| `index.html` | только разметка; в `<head>` — тема, масштаб, ключ до первой отрисовки |
| `base.css` | цвета тем, шрифты, верхняя панель, настройки, общие кнопки/переключатели/сообщения, движение |
| `i18n.js` | словарь `L` (ru/uk/pl) для ядра и вкладки фото; вкладки дописывают в него свои тексты |
| `core.js` | `api()`, общее состояние `S`, помощники (`esc`, `zl`, `toast`, `t`), верхняя панель, настройки, уведомления |
| `photo.js` + `photo.css` | вкладка «Обработка фото»; в конце файла — запуск окна (`applyStatic`, `tick`) |
| `svk.js` + `svk.css` | СВК, переключение вкладок (`setMode`, ⌘1…⌘5), заголовок окна |
| `clients.js` + `clients.css` + `templates.js` | клиенты, калькулятор, сообщения, подбор квартир |
| `owners.js` + `owners.css` | собственники, скрипт звонка, SMS, статистика, перезвоны |

Правило имён в CSS: у каждой вкладки свои приставки (`sv-`, `cl-`/`mt-`, `ow-`/`cb-`/`sms-`).
Один и тот же класс в двух файлах ломает вёрстку другой вкладки — это ловит `tools/css_check.py`.

## Данные у пользователя (`_program/`, в GitHub не попадают)

`telegram.txt` (токен бота), `app_settings.json`, `app_svk.json`, `app_clients.json`, `app_searches.json`,
`app_market.json`, `app_owners.json`, `app_calls.json`, `templates/` (шаблон договора), модели `*.pt`/`*.pth`,
`.venv`, `app_log.txt`. Квартиры — в `Hermea Photo/Квартиры/<название>/` (`hermea/` готовые фото,
`oryginal/`, `opis.txt`, `opis_otodom.txt`, `.hermea.json`).

## Проверки (`tools/`)

| Команда | Что проверяет |
|---|---|
| `python3 tools/check.py` | всё сразу (то же запускается перед каждым релизом) |
| `python3 tools/test_units.py` | даты и телефоны перезвонов, подбор, OLX, тексты Otodom, дубли поиска, переводы сервера |
| `python3 tools/test_api.py` | запускает сервер на временной папке и проходит все адреса окна |
| `python3 tools/test_ui.py` | окно в настоящем Chrome: все вкладки без ошибок JS, снимки в `/tmp/hermea_ui/` (нужен playwright) |
| `python3 tools/css_check.py` | один CSS-класс не задан в разных файлах |
| `node tools/js_check.js program/app/index.html program/app` | тексты окна: одинаковые ключи в ru/uk/pl |
| `tools/ci_smoke.py` | установка «как у коллеги» на Mac и Windows в GitHub Actions |

## Новая версия

1. Поменять файлы в `program/`, дописать заметки в `tools/notes.json` (ru/uk/pl).
2. `python3 tools/build_manifest.py X.Y.Z` — сначала прогоняет `tools/check.py`, при ошибке не собирает.
3. Закоммитить и запушить; через 3–5 минут GitHub отдаёт новую версию, программы обновляются сами.
