HERMEA: обработка фото квартир

САМЫЙ ПРОСТОЙ СПОСОБ: приложение Hermea
  1. Дважды кликни «Hermea» (значок с буквой H в папке «Hermea Photo»).
     Можно перетащить его в Dock, чтобы всегда было под рукой.
  2. Вставь ссылку на объявление и нажми «Создать».
  3. Фото появятся прямо в окне, описание можно скопировать кнопкой,
     всё сразу уйдёт в Telegram. Папка квартиры — как раньше, в «Квартиры».
  Если Hermea не открывается: правый клик → Открыть → Открыть.
  Если macOS спросит доступ к папке «Рабочий стол» — нажми «Разрешить».
  Запасной вариант: _program/Открыть окно Hermea.command

СТАРЫЙ СПОСОБ (через файл ссылок) по-прежнему работает:

HERMEA: автоматическая обработка фото с Otodom

ОДИН РАЗ, установка:
  1. Открой Терминал (Cmd+Пробел → «Терминал»).
  2. Напиши bash и пробел, перетащи в окно файл _program/Установка.command, нажми Enter.
  3. Подожди 5–10 минут, пока не появится «✓ Готово!».

КАЖДЫЙ РАЗ:
  1. Вставь ссылки Otodom в «ссылки.txt» (по одной на строку) и сохрани.
  2. Дважды кликни «Запустить.command».
     (Если macOS не даёт открыть: правый клик → Открыть → Открыть.)
  3. Для каждой квартиры появится своя папка:
       hermea/    готовые фото
       oryginal/  исходники
       opis.txt   черновик описания на украинском, проверь перед публикацией

Уже обработанные ссылки пропускаются, их можно не удалять.
Свой логотип: положи PNG с прозрачным фоном как _program/logo.png, и он будет ставиться вместо нарисованного.

ОТПРАВКА В TELEGRAM (по желанию, настраивается один раз):
  1. В Telegram открой @BotFather → /newbot → придумай имя → он пришлёт токен
     (длинная строка вида 1234567890:AAH...).
  2. Добавь этого бота в чат, куда слать квартиры, и напиши в чате /start
  3. Открой telegram.txt и вставь токен после TOKEN= и сохрани.
  4. Запусти программу: она сама найдёт чат и запишет CHAT_ID.
  После этого каждая готовая квартира приходит в чат: альбом фото + описание.

СВК (ВКЛАДКА СВЕРХУ «СВК»):
  В течение дня жми «+», когда что-то случилось: лид (прямой клиент, риэлтор, дежурство),
  публикация, показ, договор, отказ. Время записывается само, всё видно в «Журнале дня».
  Клавиши на экране дня: 1, 2, 3 — лид нужного типа; стрелки — соседний день.
  Число можно ввести руками: кликни по нему. План дня меняется кликом по «из N».
  Вечером: «Отчёт» → «Копировать отчёт» (текст для чата)
  или «Копировать для таблицы» → клик в ячейку «План» нужного дня в строке лидов → ⌘V.
  Вкладки «Неделя» и «Месяц» показывают таблицу как в СВК, с процентом выполнения.
  Данные лежат в _program/app_svk.json.

ОБНОВЛЕНИЯ:
  Программа сама проверяет обновления (настройки → «Проверить обновления»).
  Переустанавливать ничего не нужно: жмёшь «Обновить», окно перезапускается само.
